# 💫 About Me:
I am a DevOps Engineer with hands-on experience designing, automating, and scaling cloud-native infrastructure. I bridge the gap between development and operations, focusing on building secure, reliable, and high-performance CI/CD pipelines and Kubernetes-orchestrated environments.<br><br>🚀 What I Do<br>Infrastructure as Code (IaC): Provisioning and managing immutable infrastructure using Terraform and Ansible.<br><br>CI/CD Automation: Building robust, automated pipelines with GitHub Actions, GitLab CI, and Jenkins to streamline deployments.<br><br>Containerization & Orchestration: Deploying and scaling microservices using Docker, Kubernetes, and Helm.<br><br>Cloud Platforms: Architecting and maintaining scalable solutions primarily on AWS (or GCP/Azure).<br><br>Observability: Setting up proactive monitoring, logging, and alerting stacks using Prometheus, Grafana, and ELK.<br><br>Security & Compliance: Integrating DevSecOps practices early into the software delivery lifecycle.
